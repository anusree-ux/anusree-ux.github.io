Key Features

⚡ Automated CI/CD Pipeline

Git push triggers the Jenkins pipeline, which runs validation checks, builds Docker images, performs Trivy security scans, pushes images to Docker Hub, and updates Kubernetes deployment configurations for ArgoCD synchronization.

🛡️ DevSecOps & Security

Integrated Trivy container image scanning into the CI pipeline and implemented Kubernetes NetworkPolicies to control service communication and restrict database access.

📈 Monitoring & Logging

Implemented Kubernetes monitoring using kube-prometheus-stack for cluster and application metrics, Grafana dashboards for visualization, and Loki with Promtail for centralized log collection.

⚙️ Kubernetes Configuration & Scaling

Used Kustomize overlays to manage environment-specific configurations without duplication and configured Horizontal Pod Autoscaling (HPA) to automatically scale application replicas based on resource usage.
