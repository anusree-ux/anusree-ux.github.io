Capstone Architecture

Microservices GitOps Platform

This project highlights end-to-end continuous deployment using GitOps principles on a local Kubernetes cluster created with Kind.

> PIPELINE ARCHITECTURE HIGHLIGHTS
Code commit triggers automated build & unit tests in Jenkins.
Trivy scans docker images for Critical/High vulnerabilities before pushing to registry.
Argo CD continuously syncs Kustomize manifests from Git into the Kubernetes cluster.
Prometheus monitors CPU/Memory utilization and triggers HPA scaling from 1 to 5 replicas.
